# Review Queue — [Mata Kuliah]

Gunakan daftar ini untuk topik yang perlu diingat kembali, bukan untuk menumpuk semua materi.

| Topik | Alasan masuk queue | Status | Terakhir latihan | Review berikutnya | Catatan |
|---|---|---|---|---|---|
|  |  | rapuh / cukup / kuat | YYYY-MM-DD | YYYY-MM-DD |  |

## Aturan sederhana

- `rapuh`: prioritaskan review terdekat;
- `cukup`: ulangi setelah jeda;
- `kuat`: keluarkan dari queue setelah beberapa kali berhasil tanpa bantuan;
- jika kembali salah, masukkan lagi tanpa menganggap kemajuan sebelumnya hilang.
