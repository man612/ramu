# Riwayat perubahan pack — UT S1 Akuntansi Semester 2 (16 SKS)

Riwayat ini membahas **konfigurasi pack yang dipublikasikan**, bukan versi aplikasi Ramu atau log CI. Ubah bagian ini bila `pack_version` dinaikkan akibat perubahan Project Instructions, isi course pack, atau metadata yang dipakai pengguna.

## 2026-2027.s2.1

- Baseline maintained pack untuk tahun akademik **2026/2027**. Daftar mata kuliah, Project Instructions, dan course pack merujuk manifest pada direktori ini.
- Pack berstatus **source-verified**, bukan `verified` secara perilaku. Native ChatGPT Projects manual evaluation dan pilot belum diklaim selesai.
- Untuk Project yang telah dipasang, pembaruan repository/website semata **tidak** mengharuskan unggah ulang.

## Bila versi berikutnya berubah

Tambahkan heading `## <pack_version baru>` dan tulis dengan jelas: bagian apa yang berubah, apakah pengguna perlu memperbarui Project Instructions, mengganti file course pack tertentu, atau cukup memeriksa metadata. Jangan menyarankan menghapus Project, chat, dan materi pribadi tanpa alasan.

Lihat [panduan pembaruan Project](../../../../../docs/PANDUAN-UPDATE-PROJECT.md).
