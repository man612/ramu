Dilakukan sekali

Periksa pengaturan Memory ChatGPT.

Agar konteks mata kuliah tidak bercampur dengan chat lain, gunakan Project-only memory. Untuk Project baru, pilih Project-only saat membuat Project. Untuk Project yang sudah ada, coba buka ⋯ → Project settings → Memory. Jika pilihan Memory belum muncul pada akun atau versi aplikasi yang kamu pakai, buat Project baru dengan Project-only memory lalu pindahkan chat penting yang masih diperlukan.

ChatGPT→Settings→Personalization→Memory
Tentang tampilan ChatGPT

Nama menu dan ketersediaan opsi dapat berubah antar plan, akun, atau versi aplikasi. Perubahan Memory pada Project lama juga dapat membutuhkan waktu untuk berlaku. Ramu tidak bergantung pada Study Mode atau menu tambahan tertentu.

Tentang privasi

Pengaturan Data Controls adalah pilihan akunmu dan bukan syarat Ramu. Ramu sendiri adalah site statis; file kuliah pribadi tetap kamu tambahkan langsung ke Project ChatGPT, bukan diunggah ke server Ramu.

2

Salin untuk pack aktif

Pasang Project Instructions.

Project Instructions adalah aturan runtime Ramu untuk pack yang sedang dipilih dan letaknya bukan di Sources. Setelah membuat Project, buka ⋯ → Project settings → Project Instructions, lalu tempel teks Ramu. Satu Project memakai instruksi pack aktif tersebut; course pack mata kuliah dipasang terpisah sebagai source.

PROJECT INSTRUCTIONSInstruksi runtime pack aktif

3

Pilih satu dulu untuk percobaan

Tambahkan satu course pack lewat Sources.

Pilih mata kuliah dari pack aktif, unduh file .txt, lalu tambahkan file tersebut sebagai reference/source di Project. Di dokumentasi OpenAI saat ini, Project dapat menerima file melalui area Project Sources; nama tombol seperti Add source atau label sejenis dapat berubah antar versi aplikasi. Setelah Project pertama berfungsi, kamu bebas berhenti di satu atau lanjut menyiapkan mata kuliah lain.
