Dilakukan sekali

Periksa pengaturan Memory ChatGPT.

Tujuannya agar Project dapat menggunakan percakapan di dalam ruang mata kuliah tersebut sebagai konteks. Saat membuat Project nanti, pilih Project-only memory agar konteksnya tetap terpisah dari chat di luar Project.

ChatGPT→Settings→Personalization→Memory
Tentang privasi

Kalau kamu ingin mengatur apakah percakapan boleh digunakan untuk membantu peningkatan model, buka Settings → Data Controls → Improve the model for everyone. Pengaturan ini adalah pilihan akunmu dan bukan syarat untuk menggunakan Ramu.

2

Salin satu kali

Pasang Project Instructions.

Project Instructions adalah aturan dasar Ramu dan letaknya bukan di Sources. Setelah membuat Project, buka ⋯ → Project settings → Project Instructions, lalu tempel teks Ramu. Instruksi yang sama bisa dipakai ketika nanti kamu menambah Project mata kuliah lain.

PROJECT INSTRUCTIONSSatu instruksi dasar untuk semua mata kuliah

Course pack mata kuliah dipasang terpisah melalui Sources.

3

Pilih satu dulu untuk percobaan

Tambahkan satu course pack lewat Sources.

Pilih mata kuliah yang ingin kamu coba, lalu unduh paket .txt dari kartu di bawah. Setelah itu buka Project → Sources → Add source → Upload files dan pilih file tersebut. Kalau file sudah ada di Library, kamu bisa memakai Add from library. Setelah Project pertama berfungsi, kamu bebas berhenti di satu dulu atau lanjut menyiapkan mata kuliah lain.

Begitu 1 Project selesai

Langsung pakai. Tidak perlu menunggu 5/5.

Pilih Project mata kuliah yang baru selesai disiapkan lalu mulai belajar di sana. Kalau sudah terasa berguna, kembali ke halaman ini dan ulangi langkah yang sama untuk mata kuliah lain. GitHub tidak perlu dibuka setiap kali ada tugas.

Kalau ada catatan penting yang perlu dibawa ke chat berikutnya

Minta Ramu membuat Catatan Belajar Terbaru, lalu gunakan menu pada respons ChatGPT untuk Save to project / Add to project sources jika opsi itu tersedia. Saat catatan baru menggantikan yang lama, hapus versi lama supaya Project tidak membaca dua state yang bertentangan.

Saran: gunakan satu chat untuk satu tugas atau satu topik besar. Riwayatnya akan lebih mudah ditemukan kembali.
