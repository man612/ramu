Ramu itu apa?

Anggap saja Ramu sebagai paket pengaturan kuliah untuk ChatGPT.

Kamu tidak perlu memahami prompt engineering, struktur repo, atau istilah teknis lain.

Di awal semester, kamu cukup menyiapkan satu Project untuk setiap mata kuliah. Setelah itu, buka Project yang sesuai, kirim soal atau materi, lalu jelaskan kebutuhanmu dengan bahasa biasa.

Tanpa Ramu

Setiap chat sering terasa mulai dari awal.

  • mata kuliah perlu dijelaskan ulang;
  • sumber mudah tercampur;
  • aturan tugas bisa terlewat;
  • feedback lama sulit ditemukan kembali.
Dengan Ramu

Setiap mata kuliah memiliki ruangnya sendiri.

  • konteks mata kuliah sudah tersedia;
  • prioritas sumber lebih jelas;
  • cara pemeriksaan mengikuti jenis tugas;
  • feedback penting bisa digunakan kembali.

Cara pakai

Hanya ada dua bagian yang perlu diingat.

Setup dilakukan sekali di awal semester. Setelah itu, kegiatan sehari-hari tetap dilakukan di ChatGPT.

Cara kerja Ramu

Beberapa hal dijaga di belakang layar agar Project tetap rapi.

Kamu tidak perlu mengatur bagian ini satu per satu. Aturannya sudah ikut di Project Instructions dan paket mata kuliah.

Sumber yang sesuai

Memilih sumber berdasarkan jenis pertanyaan dan masa berlakunya.

Aturan tugas

Mendahulukan rubrik, instruksi tutor, dan ketentuan kampus.

Konteks per mata kuliah

Menjaga satu mata kuliah tetap berada di Project-nya sendiri.

Materi utama

BMP, bahan tutor, soal, dan materi kelas tetap menjadi dasar belajar.

Pemeriksaan akhir

Memeriksa isi, hitungan, sumber, dan format sebelum jawaban dianggap selesai.

Pertanyaan umum

Kalau baru pertama kali melihat Ramu.

Apakah Ramu aplikasi baru?

Bukan. Ramu adalah konfigurasi dan paket mata kuliah yang dipasang ke fitur Projects di ChatGPT.

Apakah harus memahami GitHub?

Tidak. GitHub hanya menjadi tempat penyimpanan panduan dan file Ramu. Setelah setup selesai, kegiatan kuliah tetap dilakukan di ChatGPT.

Kenapa tidak dibuat satu Project untuk seluruh semester?

Karena setiap mata kuliah memiliki sumber, jenis tugas, cara perhitungan, dan riwayat yang berbeda. Pemisahan membuat konteks lebih bersih.

Apakah Ramu hanya untuk mengerjakan tugas?

Tidak. Kamu juga bisa menggunakannya untuk memahami materi, memeriksa jawaban, berlatih, atau meninjau feedback tutor.

Apakah Ramu resmi dari UT atau OpenAI?

Tidak. Ramu adalah proyek independen. Data akademik dan aturan kampus tetap dirujuk dari sumber resmi.
