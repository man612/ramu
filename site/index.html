Ramu itu apa?

Anggap saja Ramu sebagai workspace belajar yang sudah diramu untuk ChatGPT.

Kamu tidak perlu memahami prompt engineering, schema, eval, atau struktur repo untuk memakainya.

Project Instructions dan course pack memberi ChatGPT konteks dasar, aturan source, dan pola bantuan. Repo di belakangnya menjaga kontrak, freshness sumber, dan skenario evaluasi agar perubahan tidak dilakukan secara asal.

Tanpa Ramu

Setiap chat mudah kembali menjadi percakapan generik.

  • mata kuliah perlu dijelaskan ulang;
  • sumber baru dan lama mudah tercampur;
  • aturan tugas bisa terlewat;
  • AI dapat terlalu cepat memberi jawaban akhir.
Dengan Ramu

Setiap mata kuliah memiliki ruang dan kontraknya sendiri.

  • konteks mata kuliah sudah tersedia;
  • prioritas sumber lebih jelas;
  • bantuan belajar mengikuti guardrail;
  • perilaku penting punya eval regression.

Cara pakai

Coba kecil dulu. Tidak perlu setup satu semester sekaligus.

Public beta sengaja memakai jalur satu mata kuliah lebih dulu supaya manfaat dan friction setup bisa kelihatan sebelum kamu memasang Project lain.

Cara kerja Ramu

Beberapa hal dijaga di belakang layar agar Project tetap disiplin.

Kamu tidak perlu mengatur bagian ini satu per satu. Aturannya sudah diringkas ke Project Instructions dan course pack, sedangkan repo menyimpan protokol dan eval untuk memeriksa regresi.

Sumber yang sesuai

Memilih sumber berdasarkan jenis pertanyaan, otoritas, dan masa berlakunya.

Aturan tugas

Mendahulukan rubrik, instruksi tutor, dan ketentuan kampus.

Konteks per mata kuliah

Menjaga satu mata kuliah tetap berada di Project-nya sendiri.

Materi utama

BMP, bahan tutor, soal, dan materi kelas tetap menjadi dasar belajar saat tersedia.

Pemeriksaan perilaku

Guardrail penting tidak hanya ditulis, tetapi juga dibuat sebagai contract dan behavior eval.

Batas yang tetap dijaga

Ramu tidak membuat AI otomatis selalu benar.

01

Materi berhak cipta tidak disalin ke repo

BMP atau bahan kelas yang memang kamu miliki ditambahkan sendiri ke Project saat diperlukan.

02

Informasi yang berubah perlu diperiksa ulang

Contohnya aturan pajak atau fitur produk AI. Sumber resmi terbaru harus diprioritaskan.

Model AI bukan dependency permanen

Ramu tidak mengunci satu nama model. Model kandidat dan judge dicatat saat behavior eval benar-benar dijalankan.

04

Public beta bukan klaim fully validated

Static checks sudah otomatis; behavior eval nyata dan pilot pengguna tetap perlu dijalankan dan direview.

Pertanyaan umum

Kalau baru pertama kali melihat Ramu.

Apakah Ramu aplikasi atau model AI baru?

Bukan. Ramu adalah framework konfigurasi dan evaluasi yang dipasang ke Projects di ChatGPT.

Apakah harus memahami GitHub?

Tidak. GitHub menjadi tempat source, dokumentasi, dan pemeriksaan Ramu. Setelah setup selesai, kegiatan kuliah tetap dilakukan di ChatGPT.

Harus setup lima Project sekaligus?

Tidak. Untuk public beta justru disarankan mulai dari satu mata kuliah. Kalau cocok, baru tambah Project lain.

Model ChatGPT apa yang wajib dipakai?

Tidak ada nama model yang dikunci permanen oleh Ramu. Model dan batas paket dapat berubah. Untuk eval, model yang benar-benar diuji dipilih dan dicatat saat run.

Apakah Ramu sudah terbukti selalu lebih baik?

Belum ada klaim seperti itu. Ramu punya landasan desain, contract test, source monitoring, dan behavior eval; efektivitas penggunaan nyata tetap perlu diuji melalui pilot dan run eval yang direview.

Apakah Ramu resmi dari UT atau OpenAI?

Tidak. Ramu adalah proyek independen. Data akademik dan fitur platform tetap dirujuk dari sumber resmi.
