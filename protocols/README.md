# Protokol Belajar Ramu

Folder ini menjelaskan perilaku Ramu berdasarkan maksud mahasiswa. Protokol ini adalah **spesifikasi desain dan evaluasi**, bukan file tambahan yang wajib diunggah pengguna ke setiap Project.

Runtime yang benar-benar dipasang ke ChatGPT tetap sederhana:

- `PROJECT-INSTRUCTIONS.md` memuat aturan perilaku inti;
- satu course pack memuat konteks dan verifier mata kuliah;
- file materi/rubrik milik mahasiswa ditambahkan saat diperlukan.

Detail di folder `protocols/` dipakai untuk menjaga desain tetap konsisten, menulis eval, dan memastikan aturan penting tidak hilang ketika Project Instructions diringkas. Jadi pengguna tidak perlu mengunggah empat file protokol ini satu per satu.

Urutan keputusan:

1. kenali maksud utama: belajar, tugas, review, riset, latihan ujian, atau membaca feedback;
2. baca soal, rubrik, kebijakan penggunaan AI, dan materi yang diberikan;
3. pilih perilaku yang sesuai;
4. terapkan verifier khusus mata kuliah;
5. tutup dengan pemeriksaan akhir dan, bila berguna, catatan kemajuan belajar.

Jika satu percakapan memiliki beberapa maksud, gunakan perilaku yang paling dekat dengan tujuan saat itu. Aturan tugas dan integritas akademik selalu mengalahkan kebiasaan format Ramu.

Protokol yang tersedia:

- [`belajar.md`](belajar.md) — memahami konsep dan membangun kemampuan, bukan sekadar memperoleh jawaban;
- [`tugas.md`](tugas.md) — membantu tugas dengan tetap mengikuti rubrik dan aturan penggunaan AI;
- [`review.md`](review.md) — memeriksa jawaban, menemukan pola kesalahan, dan mengubah feedback menjadi pelajaran;
- [`latihan-ujian.md`](latihan-ujian.md) — retrieval practice, latihan tanpa bantuan berlebihan, dan pengulangan terjadwal.
