# Zona Konteks

Zona Konteks menjaga informasi tetap berada di ruang yang relevan.

Default Ramu:

- **1 mata kuliah = 1 ChatGPT Project**;
- **1 tugas/topik besar = 1 chat baru** di dalam Project tersebut;
- gunakan `project-only memory` jika tersedia;
- jangan menjadikan satu chat sebagai percakapan tanpa akhir sepanjang semester;
- hal penting yang harus bertahan lama disimpan sebagai sumber eksplisit, bukan hanya mengandalkan memory percakapan.

Pemisahan ini dipilih karena konteks panjang dan padat dapat menurunkan keterandalan retrieval, sementara Project memory sendiri belum menyediakan kontrol memory yang transparan per item.
