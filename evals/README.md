# Evals

Folder ini berisi skenario uji untuk mengecek perilaku konfigurasi Ramu.

Evals awal bersifat **manual** karena Ramu dipakai melalui ChatGPT Projects, bukan aplikasi API yang punya runner sendiri. Tujuannya tetap sama: perubahan instructions/course pack tidak boleh dianggap aman hanya karena terlihat rapi.

## Kriteria umum

Sebuah skenario minimal mencatat:

- input;
- konteks/file yang tersedia;
- perilaku yang diharapkan;
- kondisi gagal;
- catatan hasil uji;
- tanggal/model/permukaan aplikasi ketika diuji.
